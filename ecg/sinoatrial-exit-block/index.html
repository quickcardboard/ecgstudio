Sinoatrial exit block

In sinoatrial (SA) exit block the sinus node keeps firing but some impulses fail to leave it, so a whole P–QRS–T complex is missing. In second-degree type II SA block the pause is an exact multiple of the normal P–P interval.

What the simulator reads

Sinus rhythm with 2nd-degree SA exit block

Rate 48 bpm · PR 136 ms · QRS 85 ms · QT/QTcF 367/390 ms · Axis +26° · normal axis

ECG criteria

  • Pauses with a missing P wave and QRS complex
  • Type II: the pause is exactly twice (or a multiple of) the P–P interval
  • Type I (Wenckebach): P–P intervals shorten before the pause, and the pause is shorter than two P–P intervals
  • Normal P-wave shape and PR interval in the conducted beats

Why it looks like this

The sinus node's discharge is invisible on the surface ECG; only the atrial depolarisation it produces is seen. When conduction from the node into the atrium fails intermittently, a beat drops out while the node's own rhythm continues, which is why the pause fits the underlying cycle. Sinus arrest, by contrast, is a failure of the node to fire, and the pause has no fixed relation to the P–P interval.

Differential diagnosis

  • Sinus arrest or pause (the pause is not a multiple of the P–P interval)
  • Non-conducted premature atrial beat (an early P wave in the T wave)
  • Sinus arrhythmia
